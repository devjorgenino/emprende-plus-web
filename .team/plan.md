# Plan — Rediseño Profesional Emprende+ Web

## Goal
Rediseñar completamente la interfaz de Emprende+ Web para que se vea profesional, manteniendo todas las funcionalidades existentes. Enfoque en paleta corporativo-tech premium.

## Size
**L** — Trabajo de frontend a gran escala: cambio de tokens de diseño global, rediseño de componentes base, layout moderno, animaciones y optimización de rendimiento.

## Split
- **T0** Design System Tokens (colores, tipografía, espaciado, sombras) — Tech Lead
- **T1** Componentes base (Button, Input, Card, Modal, Select, NavBar, Layout) — dev-frontend
- **T2** Dashboard + Features principales (Services, Sales, Inventory) — dev-frontend
- **T3** Features restantes (Clients, Expenses, Calculator, Settings, Quotes) — dev-frontend
- **T4** UX/UI polish (animaciones, transiciones, estados de carga, feedback) — dev-frontend
- **T5** Performance optimization (lazy loading, bundle optimization, PWA tweaks) — dev-frontend

## Design Direction
- **Primary**: Azul oscuro corporativo `#0F172A` (slate-900)
- **Secondary**: Azul eléctrico premium `#6366F1` (indigo-500) + Verde esmeralda `#10B981` (emerald-500)
- **Accent**: Cian `#06B6D4` (cyan-500)
- **Background**: Gris claro `#F8FAFC` (slate-50)
- **Surface**: Blanco `#FFFFFF`
- **Dark mode**: Gris oscuro `#0F172A` con acentos brillantes
- **Typography**: Inter (sans-serif) con jerarquía clara
- **Radius**: rounded-lg (8px), rounded-xl (12px), rounded-2xl (16px)
- **Shadows**: Sutil, con elevación sutil en cards
