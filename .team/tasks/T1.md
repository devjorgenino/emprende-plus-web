# T1 — Componentes base (Button, Input, Card, Modal, Select, NavBar, Layout)
Owner: dev-frontend

Goal: Rediseñar todos los componentes UI base con la nueva paleta corporativo-tech premium. Los componentes deben ser consistentes, accesibles y con feedback visual adecuado.

Files:
- src/components/ui/Button.tsx
- src/components/ui/Card.tsx
- src/components/ui/Input.tsx
- src/components/ui/Select.tsx
- src/components/ui/Modal.tsx
- src/components/layout/Layout.tsx
- src/components/layout/NavBar.tsx

Contract:
- Colores: usar variables CSS definidas en src/index.css (primary, secondary, accent, success, error, text, textSecondary, textMuted, background, surface, border)
- Sombras: usar las clases shadow-elevation-1, shadow-elevation-2, shadow-elevation-3, shadow-elevation-4
- Border radius: rounded-lg, rounded-xl, rounded-2xl
- Transiciones: duration-200 o duration-300
- Tipografía: Inter, pesos medium (500) para labels, semibold (600) para títulos

Acceptance criteria:
- [ ] Todos los componentes usan las nuevas variables de color
- [ ] Botones tienen estado loading con spinner
- [ ] Modal tiene botón de cierre y animación fade-in
- [ ] Input tiene feedback visual en focus y error
- [ ] NavBar usa el nuevo color secondary para el estado activo
- [ ] Layout tiene logo/icono visual en el header
- [ ] Build pasa sin errores: `npm run build`
- [ ] Componentes funcionales en el navegador

Run: `npm run build && npm run dev`
