# T0 — Design System Tokens (colores, tipografía, espaciado, sombras)
Owner: Tech Lead

Goal: Establish the complete visual design system for Emprende+ Web: color tokens, typography scale, spacing scale, border radius, shadows, and component base styles. This is the foundation for all subsequent UI work.

Files:
- src/index.css
- tailwind.config.ts
- src/constants/colors.ts (update if exists)
- src/constants/layout.ts (update if exists)

Contract:
- Colors must support both light and dark mode via Tailwind `darkMode: 'class'` (already configured).
- Dark mode colors: slate-900 background, slate-800 surface, slate-50 text, indigo-400 accent.
- All color tokens must be defined as CSS variables in `:root` and `.dark` so components can use `var(--color-*)` or Tailwind utility classes.
- Typography: Inter font, clear hierarchy (h1 2xl bold, h2 xl bold, h3 lg medium, body base regular, text-sm secondary).
- Radius: 8px (lg), 12px (xl), 16px (2xl).
- Shadows: subtle elevation, stronger on hover.

Acceptance criteria:
- [ ] `npm run typecheck` passes (no type errors).
- [ ] `npm run build` succeeds.
- [ ] Light and dark mode both render with the new palette (verified visually).
- [ ] All existing Tailwind utility classes referenced in components still resolve (no missing color names like `bg-primary`, `text-text`, `border-border`).

Run: `npm run typecheck && npm run build`
