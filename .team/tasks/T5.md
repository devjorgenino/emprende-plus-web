# T5 — Performance optimization (lazy loading, bundle optimization, PWA)
Owner: dev-frontend

Goal: Optimizar el rendimiento de la aplicación con lazy loading de features, code splitting, optimización de assets, y mejoras al PWA.

Files:
- vite.config.ts (actualizar optimización)
- src/App.tsx (añadir lazy loading con React.lazy)
- src/components/ui/ (optimizar imports)
- public/ (optimizar assets)
- src/services/ (optimizar db)

Contract:
- Usar React.lazy + Suspense para features pesadas
- Code splitting por ruta con Vite
- Prefetch de chunks críticos
- Optimizar íconos de lucide-react (tree shaking)
- PWA: cache strategies, offline fallback

Acceptance criteria:
- [ ] Bundle size < 500KB gzipped (actualmente ~200KB - bueno)
- [ ] First Contentful Paint < 1s en carga inicial
- [ ] Features cargan bajo demanda con lazy loading
- [ ] PWA funciona offline con cache sensible
- [ ] No errores en consola en modo producción
- [ ] Build pasa sin errores: `npm run build`

Run: `npm run build && npm run dev`
